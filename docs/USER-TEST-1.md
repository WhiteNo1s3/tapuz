# מבחן משתמש #1 — "קל להבין" עומד למבחן (v1.68)

המטרה מנוסחת בחזון: בונה אתרים **קל להבין** שמלווה אותך — לא "תקראו את התווית".
v1.66 שלח את הסיור המודרך; המסמך הזה הופך את בדיקת האמת (הבוחנת: אחות של בן)
מ"שווה לבדוק מתישהו" לפרוטוקול של 30 דקות שאפשר להריץ היום.

## כללי ברזל למנחה (בן)

1. **לא עוזרים.** כל "רגע, איפה ה..." נרשם — הוא הממצא. עוזרים רק אחרי
   שנרשם, ורק אם היא תקועה מעל דקה.
2. **לא מסבירים מראש.** המערכת אמורה להסביר את עצמה — זה מה שנבדק.
3. **חושבים בקול.** מבקשים ממנה לומר מה היא מחפשת בכל רגע.
4. מתחילים מדפדפן נקי (או Ctrl+Shift+N) — כדי שהסיור יופיע כביקור ראשון.

## מה רושמים — טופס תוצאה (למלא תוך כדי)

לכל משימה: **הצליחה לבד / הצליחה עם רמז / נתקעה** + ציטוט אחד שלה
(המילים שלה שוות יותר מכל ניתוח).

```
משימה 1: [ ] לבד  [ ] רמז  [ ] נתקעה   ציטוט: ____________
משימה 2: [ ] לבד  [ ] רמז  [ ] נתקעה   ציטוט: ____________
... (עד 8)
שאלת סיום 1: "מה היה הכי מבלבל?"        ____________
שאלת סיום 2: "מה היית מצפה שיקרה אחרת?"  ____________
שאלת סיום 3: "1–10, כמה היית מסתדרת לבד?" ____________
```

## סף הצלחה (נקבע מראש, שלא נרמה את עצמנו)

- **עובר:** 6 מתוך 8 משימות "לבד", ואף משימה לא "נתקעה" מעל דקה.
- **נכשל חלקית:** כל משימה שנזקקה לרמז → הצעד המקביל בסיור נכתב מחדש.
- **נכשל:** אם משימות 2 או 4 (גרירה / שחרור לפי כוונה) נתקעו — הליבה של
  "קל להבין" לא עומדת, וזה קודם לכל פיצ'ר חדש.

## אחרי המבחן

את הטופס המלא מדביקים בגיליון הזה מתחת לקו, עם תאריך. הממצאים הופכים
לשורות עבודה ב-ROADMAP — כל "רמז" = באג בהדרכה, לא באג אצל הבוחנת.
