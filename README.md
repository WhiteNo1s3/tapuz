# Tapuziel

**תפוזיאל** — CMS פשוט, יפה, ובעברית. (Tapuz + שאלתיאל = התפוז עם הכנפיים)

**גרסה נוכחית: v2.36-alpha** · המפה המלאה: [docs/ROADMAP.md](docs/ROADMAP.md)

- פלט HTML נקי וסמנטי, RTL מלא
- **אשף התקנה מודרך** — מהרעיון לאתר חי בארבעה צעדים (שם → צבעים → דפים → תפריט)
- **דף פתיחה שמלמד** — האתר נולד עם סיור צבעוני בארגז הכלים: גלריה, קרוסלה, מבזקים, טקסט נע, מיכלים ותפריט שני. כל קטע הוא מודול אמיתי — ערכו, גררו או מחקו
- **בונה דפים ויזואלי** — מודולים (Hero, טקסט, תמונה, גלריה, וידאו, קוביות מאמרים...), גרירה, פיצול לטורים, פאנל מאפיינים בצד
- **סיור מודרך בבונה** — בכניסה הראשונה הבונה מלווה אתכם בחמישה צעדים על הממשק האמיתי: ארגז → גרירה לפי כוונה → הגדרות → נייד → טיוטה/פרסום. מלמד את *הפעולה*, לא את התווית — וזמין תמיד מכפתור 🧭
- **שחרור לפי כוונה** — כל שטח המודול קולט גרירה: חלק עליון/תחתון = לפני/אחרי, מרכז של מיכל = פנימה, קצוות = פיצול לטורים — עם סימון חי של מקום הנחיתה
- **מערכת מאמרים** — כל דף שמסומן "דף מאמר" מופיע אוטומטית בקוביות (תמונה + כותרת + תקציר)
- **סטודיו ערכות הנושא** — 15 מראות מוכנים שהם ערכות שלמות (גופני Google בעברית, רקעי דף, סגנון כפתורים, שלד ועור), ו**מעצב/ת ערכות ב-AI**: מתארים את האתר שבדמיונכם, מעתיקים פרומפט לצ׳אט חדש, מדביקים את התשובה — הערכה נכנסת לספרייה, **הקנבס מראה אותה** לפני השמירה, ולחיצה אחת מחילה. הקנבס הוא לא דף אלא ספסל של הערכה: מתחיל ריק, ומתמלא במודולים — מודבקים כ-BenTML (מהבונה, מהרולפליי בצ׳אט שלכם), מארגז המודולים, או כל סיור הארגז בלחיצה — כולל **שורות של עד 6 מודולים זה לצד זה** עם יחס רוחב לכל תא, רוחב שורה (תוכן / רחב / מסך מלא), מרווח, יישור ונקודת קריסה — רספונסיבי כמו אתר, לא כרטיסים דחוסים. אפשר גם להציג כל דף אמיתי מהאתר. **ערכה = מסמך `.bent`** ([docs/bent-theme.md](docs/bent-theme.md)): מה שמייצאים, מה שה-AI מחזיר, מה שמייבאים — BenTML, לא JSON. ייבוא סלחני (קובץ / JSON / תשובת צ׳אט עם פטפוט), ואפקטים שמקומפלים לפני שהם נקלטים
- טיוטה ≠ פרסום, היסטוריית גרסאות עם שחזור, ספריית מדיה עם תיקיות
- ייבוא מ-WordPress + Elementor, בנייה סטטית
- **ידידותי לסוכני AI** — בלוקים כ-JSON מובנה, CLI מלא, סכמות מתועדות ([docs/block-schemas.md](docs/block-schemas.md))
- **פורמט `.pzn` פתוח** — תקן מתועד ([docs/pzn-spec.md](docs/pzn-spec.md)) + סכמה מכונתית ([docs/pzn-schema.json](docs/pzn-schema.json), גם ב-`GET /pzn-schema.json`). ה-RPM שלנו — כל אחד יכול לממש קורא/כותב
- **גשר AI (BYO)** — הדביקו את התשובה של ה-ChatGPT/Claude שלכם, או תוסף כרום ([extension/](extension/)) — בלי מפתחות. **אנחנו מעתיקים, אתם מדביקים** — התוסף לעולם לא כותב בצ׳אט שלכם, רק קורא את התשובה ומפרסם
- **לוקחים רק את ה‑BenTML** — מדביקים את כל התשובה כמו שהיא, בכל מקום שמקבל טקסט מ‑AI: fence של קוד, משפטי פטפוט, סוגריים של `<html>` מסביב, תבנית ריקה שהבוט חזר עליה — הכול יורד, ונשאר רק הדף. שני הניבים (`<bent-*>` ו‑`BENTML 0.2`) מתקבלים בכל דלת ([docs/bentml-status.md](docs/bentml-status.md))
- **🧠 בונה פרומפטים בבונה הדפים** — כפתור אחד יוצר פרומפט מלא (משחק + מילון + הדף הנוכחי + הבקשה שלכם) ומעתיק ללוח — מדביקים בכל צ׳אט AI, בלי מפתח
- **קופיילוט שרואה ופועל** — מחובר במפתח שלכם: קורא את הדפים שלכם, מציע עריכה, ו**עוצר לאישור** לפני כל כתיבה. כל שינוי נשמר כטיוטה — אין פרסום, אין מחיקה, אין נגיעה בהגדרות
- **🤖 הקופיילוט בתוך הבונה** — מגירת צ׳אט בבונה הדפים שיודעת איזה דף פתוח ואיזה מודול מסומן: "הוסף לפריט המסומן טקסט..." מתכוון בדיוק לבלוק הזה. אותו שער אישורים, אותה טיוטה
- **מסדר/ת התפריטים ב-AI** — התפריט לא נשבר יותר מרוב תוכן: כותרת רחבה, שבירה לפי תוכן, תפריטי משנה אמיתיים, מגירה ☰ במסכים צרים, קיפול "עוד", סימון הדף הנוכחי — הכול CSS בלבד, כידיות בסטודיו. וכשיש 12 דפים ולא יודעים מה לשים איפה: **הזרקת המארגן** ([docs/bent-menus.md](docs/bent-menus.md)) — המערכת מחשבת כמה פריטים נכנסים בשורה, מעתיקים פרומפט לצ׳אט (או מריצים עם ה-AI המחובר), התשובה חוזרת כמסמך `<bent-menus>`, רואים תצוגה מקדימה עם הכותרת האמיתית, מחילים בלחיצה — עם גיבוי וביטול. אותה מסגרת מקבלת כל "עבודה שחורה" הבאה ([docs/INJECTIONS.md](docs/INJECTIONS.md)); הכול נבדק מול מודל מקומי ב-LM Studio דרך אותו צינור ([docs/LOCAL-LLM.md](docs/LOCAL-LLM.md))
- **ניווט חלק** — לחיצה על *כל* קישור בממשק (תפריט הצד, כרטיסי הבית, קישורים בתוכן, מסנן תיבת הפניות) מחליפה רק את התוכן; הסרגל הקבוע לא נטען מחדש ולא קופץ. מה שיוצא מהמעטפת — הורדות, בונה הדפים — נופל לרענון מלא כרגיל (וכך גם כל תקלה)
- **מודל מקומי** — LM Studio / Ollama על המחשב שלכם: בוחרים "מודל מקומי" בקופיילוט, מזינים כתובת (ברירת מחדל `http://127.0.0.1:1234/v1`) — בלי מפתח, בלי עלות, בלי שדבר יוצא מהמכונה. השרת מקבל **רק** כתובות loopback

## התחלה מהירה

```bash
node src/server.js            # פתח את הממשק (http://localhost:3000/admin)
                              # התקנה ראשונה? האשף יקבל אתכם אוטומטית

./bin/tapuz.js build          # בנה את האתר הסטטי
./bin/tapuz.js serve          # צפה באתר ב-localhost:8080
```

לבדיקות מקומיות מהירות — במקום האשף אפשר לזרוע חשבון מנהל זמני:

```bash
npm run seed:admin            # יוצר/מאפס כניסה  admin / admin  (מקומי בלבד!)
```

> ⚠️ `admin/admin` היא סיסמת פיתוח חלשה. הסקריפט מסרב לרוץ עם `NODE_ENV=production`,
> נכתב רק ל-`config/auth.json` (מחוץ ל-git), והאפליקציה עצמה לא מכילה שום חשבון ברירת־מחדל.
> החליפו סיסמה לפני כל פריסה אמיתית.

אפשר להריץ מול כל תיקיית אתר עם `TAPUZ_ROOT` (ברירת מחדל: תיקיית החבילה):

```bash
TAPUZ_ROOT=/path/to/my-site node src/server.js
```

## CLI

```bash
./bin/tapuz.js create-page "כותרת" [slug]   # דף חדש
./bin/tapuz.js add-block <slug> <type>      # הוסף מודול לדף
./bin/tapuz.js list-pages / show / preview  # עיון
./bin/tapuz.js set-menu / set-logo          # תפריט ולוגו
./bin/tapuz.js import-wp <export.xml>       # ייבוא מ-WordPress
./bin/tapuz.js build / serve                # בנייה וצפייה
```

## ייבוא מ-WordPress

1. באדמין שלך: Tools → Export → All content
2. הורד את הקובץ

```bash
./bin/tapuz.js import-wp ~/Downloads/your-export.xml
./bin/tapuz.js build
```

## פריסה לשרת

תפוזיאל הוא **שרת Node חי** (Express + SQLite), לא אתר סטטי — ואין לו שלב
בנייה. `npm run export:static` רק מייצא את הדפים המפורסמים ל-HTML, בלי אדמין,
CRM או קליטת טפסים. Docker, systemd, פרוקסי הפוך, משתני סביבה, גיבוי ושדרוג:  
[docs/DEPLOY.md](docs/DEPLOY.md)

```bash
docker compose up -d --build     # → http://localhost:3000/admin
```

דורש **Node 24 LTS** ומעלה (18 ו-20 בסוף חיים).

## לעורכי הקוד (המניפסט)

הקוד מודולרי: כל משטח ניתוב חי במודול משלו תחת [`src/routes/`](src/routes/),
ו-`src/server.js` הוא קובץ ההרכבה הרזה. שני מסמכי ניווט מחזיקים את המפה:

- [docs/ROUTE-MAP.md](docs/ROUTE-MAP.md) — **איזה קובץ מחזיק איזה route** (נוצר מהקוד עם
  `npm run gen:route-map`, שמור מפני drift ב-`smoke-route-map.js`). מחפשים היכן `/admin/X`? כאן.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — סיפור הפירוק המודולרי: הדפוס, כל חילוץ, והשיקולים.
